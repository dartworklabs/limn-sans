# Contributing

The most useful thing you can send is a rendering report: a character that draws
wrong, spaces wrong, or does not appear. [Open an issue](https://github.com/dartworklabs/limn-sans/issues/new/choose)
and the form asks for the four things that settle such a report — which character,
which release, where you saw it, and what you expected instead.

## What this repository can and cannot do for you

Install from the [release package](https://github.com/dartworklabs/limn-sans/releases/latest),
not from this tree. The repository's default build and its `site/` previews are
development tools: the default profile is the bilingual `full` 0.100, which is not
qualified for public release and can show research features absent from the
release.

**You cannot rebuild the release fonts from this checkout.** `make fonts-release`
needs three generated inputs that are not in the repository — the Latin producer
`site/limn-font-play.js`, the nine supplemental-symbol producers, and the recorded
U+3000 advance provenance — and the last of those has no producer here at all. What
you can check instead is the published
[provenance manifest](https://github.com/dartworklabs/limn-sans/releases/latest),
which binds the source commit, every input by SHA-256, the runtime, and the hash of
every file in the package. The outlines are not drawn in a font editor; they are
generated by the Python under `site/tools/`, so there are no UFO sources to send a
patch against.

If you want to change a drawing, say what is wrong and show it. A pull request
against generated data cannot be merged, because the next build overwrites it.

## Tests

`make quality` and `make test` are the CI gates and run on every pull request. They
need no build data: `make test` fetches NanumSquareRound, checked by SHA-256, and
runs the unit tests under `site/tools/`.

## Licence and names

The fonts and font data are under the [SIL Open Font License 1.1](OFL.txt). Limn
Sans declares no Reserved Font Name of its own, but it inherits two sets that still
bind: "Quicksand", and NAVER's Nanum names. If you redistribute a modified version,
keep `OFL.txt`, `OFL-Quicksand.txt` and `OFL-NanumSquareRound.txt` with it and
follow those reserved-name conditions — which means a derivative may not be called
Quicksand or Nanum anything.

The limn name, logo and wordmark are Dartwork trademarks and sit outside the font's
OFL. They are not yours to reuse under that licence.

Hangul is not part of this family. The release covers English and supported symbols;
Greek and extended Latin are included without language QA, and no language beyond
English has been signed off.
